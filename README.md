# Galette Maps plugin

[![GitHub license](https://img.shields.io/github/license/galette-plugins/plugin-maps)](https://github.com/galette-plugins/plugin-maps/blob/master/COPYING)
[![Maintained by the Galette core team](https://img.shields.io/badge/maintained_by-Galette_core_team-ffb619?style=for-the-badge&logo=php&logoColor=white)](https://galette.eu)

### English

A [Galette](https://galette.eu) plugin to geolocalize members: it stores geographical coordinates for each member, and displays the ones who agreed to be publicly visible on a map.

Map display uses [MapLibre GL](https://maplibre.org/) with [OpenFreeMap](https://openfreemap.org/) vector tiles by default — no API key, no registration, and the whole thing can be self-hosted. An administrator picks another provider, or enters their own address, from Configuration. Search is provided by the [Nominatim](https://nominatim.openstreetmap.org/) API.

This plugin is developed and maintained by the **Galette core team**, along with Galette itself — unlike most of the plugins hosted in this organization, which are community-maintained.

* website: https://galette-plugins.github.io/plugin-maps/
* bugs and features: https://bugs.galette.eu/projects/galette-plugin-maps
* mailing lists:
  * users: https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * developers: https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation: https://galette-plugins.github.io/plugin-maps/documentation.html

To use Galette Maps plugin, you'll need a reliable Galette version, and of course the plugin itself by either:

* download latest version available from the [releases page](https://github.com/galette-plugins/plugin-maps/releases)
* use [Galette Maps plugin source code from repository](https://github.com/galette-plugins/plugin-maps), this solution requires some technical skills

### Français

Un plugin [Galette](https://galette.eu) pour géolocaliser les adhérents : il enregistre les coordonnées géographiques de chacun, et affiche sur une carte ceux qui ont accepté d'être visibles publiquement.

Les cartes sont rendues par [MapLibre GL](https://maplibre.org/) à partir des tuiles vectorielles [OpenFreeMap](https://openfreemap.org/) par défaut : sans clé d'API, sans inscription, et auto-hébergeable. Un administrateur peut choisir un autre fournisseur, ou saisir sa propre adresse, depuis la Configuration. La recherche est assurée par l'API [Nominatim](https://nominatim.openstreetmap.org/).

Ce plugin est développé et maintenu par l'**équipe Galette**, comme Galette lui-même — contrairement à la plupart des plugins hébergés dans cette organisation, qui sont maintenus par la communauté.

* site web : https://galette-plugins.github.io/plugin-maps/
* bogues et fonctionnalités : https://bugs.galette.eu/projects/galette-plugin-maps
* listes de diffusion :
  * utilisateurs : https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * développeurs : https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation : https://galette-plugins.github.io/plugin-maps/fr/documentation.html

Pour utiliser le plugin Maps pour Galette, vous aurez besoin d'une version adéquate de Galette, ainsi que du plugin lui-même :

* télécharger la dernière version depuis la [page des versions](https://github.com/galette-plugins/plugin-maps/releases)
* utiliser [le code source du plugin Maps pour Galette depuis le dépôt](https://github.com/galette-plugins/plugin-maps), cette solution requiert quelques compétences techniques
